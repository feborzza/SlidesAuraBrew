A Marca

O Verão em uma Garrafa

Monitoramento IoT

Dashboard AuraBrew

Sistema de Monitoramento em Tempo Real

Dashboard web que recebe dados do sensor ESP32 continuamente, exibindo temperatura de fermentação, consumo energético e status do sistema de resfriamento automático com precisão.

Infraestrutura de Dados:

• Sensor: ESP32 + DS18B20 (precisão ±0.5°C)
• Comunicação: HTTP para transmissão de dados
• Armazenamento: Google Sheets para histórico persistente
• Visualização: Gráficos em tempo real com Chart.js
• Frequência: Leitura a cada 10 segundos

🌡️

Temperatura

Monitoramento contínuo com faixa ideal de 18°C – 24°C

❄️

Resfriamento

Controle automático de relé para manter fermentação estável

⚡

Consumo Energético

Rastreamento de kWh acumulado do sistema de refrigeração

📈

Histórico Completo

Gráficos e tabelas com dados acumulados de todo o processo

Integração do Sistema

Fluxo de Dados

ESP32 → Sensor DS18B20 → Google Sheets → Dashboard Web → Visualização em Tempo Real
1

Coleta

Sensor DS18B20 conectado ao ESP32 coleta temperatura a cada 10 segundos com precisão

2

Transmissão

ESP32 envia dados via HTTP para a planilha Google Sheets de forma segura

3

Armazenamento

Dados persistem na Google Sheets com histórico completo de todo o processo

4

Visualização

Dashboard consome dados em tempo real e exibe gráficos, KPIs e relatórios
